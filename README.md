## 📌 Présentation

**Facturation** est un projet d'application web destiné à faciliter la gestion des opérations commerciales. Il vise à centraliser les informations relatives aux clients, aux articles, aux devis, aux acomptes et aux factures dans une interface simple et accessible.

Le projet est développé progressivement avec HTML, CSS et JavaScript, dans le but de mettre en pratique les concepts du développement web et de créer un outil de gestion fonctionnel.

## ✨ Fonctionnalités

### 👥 Gestion des clients

- Consulter et organiser les informations des clients.
- Associer les documents commerciaux aux clients concernés.

### 📦 Gestion des articles

- Consulter les articles disponibles.
- Gérer les informations nécessaires à la facturation.

### 📄 Gestion des devis

- Créer des devis.
- Consulter les informations et les montants des devis.
- Suivre les différents statuts des devis.

### 💰 Gestion des acomptes

- Créer un acompte associé à un devis.
- Définir un montant ou un pourcentage d'acompte.
- Suivre les informations et le statut des acomptes.

### 🧾 Gestion des factures

- Créer des factures à partir des devis.
- Consulter les détails des factures.
- Relier les factures aux devis et aux acomptes correspondants.
- Suivre les statuts de paiement.

### 📊 Suivi des montants

- Calculer les montants des documents commerciaux.
- Suivre les sommes déjà versées.
- Déterminer le reste à payer selon les documents associés.

> Certaines fonctionnalités peuvent encore être en cours de développement. Leur disponibilité dépend de l'état actuel du projet.

## 🚀 Installation et lancement

### Prérequis

- Un navigateur web moderne.
- Git pour récupérer le projet.
- Visual Studio Code (recommandé).
- L'extension Live Server de VS Code (facultative, mais pratique).

### 1. Cloner le dépôt

```bash
git clone https://github.com/DialloMoahamed/Facturation.git
```

### 2. Accéder au dossier

```bash
cd Facturation
```

### 3. Ouvrir le projet

Avec Visual Studio Code :

```bash
code .
```

### 4. Lancer l'application

Ouvre `index.html` dans ton navigateur ou utilise l'extension Live Server pour démarrer un serveur local.

Aucune installation de dépendances Node.js n'est nécessaire pour cette méthode de lancement si le projet reste une application web statique.
